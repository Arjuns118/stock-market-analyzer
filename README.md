# Stock Market Analyzer

A machine learning-powered stock market analysis and prediction application built with **Python**, **LSTM (Long Short-Term Memory)** neural networks, and the **yfinance** API. The application fetches real-time and historical stock market data, predicts future stock prices, and provides an interactive web interface for data visualization, trend analysis, and model performance evaluation.

## Features

* Fetch real-time and historical stock market data using **yfinance**
* Predict future stock prices using an **LSTM** deep learning model
* Interactive visualization of stock price trends
* Compare actual and predicted stock prices
* Analyze model performance using evaluation metrics
* Support for multiple stock symbols
* User-friendly web interface for stock analysis

## Tech Stack

* Python
* TensorFlow / Keras (LSTM)
* yfinance
* Pandas
* NumPy
* Matplotlib / Plotly
* Streamlit (or Flask)
* Scikit-learn

## Project Objectives

* Collect historical stock market data using the **yfinance** API.
* Preprocess and normalize financial time-series data.
* Train an LSTM model to learn stock price patterns.
* Predict future stock prices based on historical trends.
* Visualize market data and prediction results through an interactive dashboard.
* Evaluate model performance using standard regression metrics.
